Star Launcher Application

Built using C# in Visual Studio Community, Star Launcher is a basic unofficial Windows program launcher focused on games, but can be used for any application. With an emphasis on utilizing low power, Star Launcher allows you to open all of your favorite apps in one convenient place while also not taking up too many resources like other launchers do. Profiles are available, so family and friends can store all their favorite apps on their own accounts when needed. You can sort games and apps by genre, rate them, customize their title and icons, and more. It also features emulator launching support for various apps (but not all). this app will only work if you have .NET Framework 8.0 installed.
